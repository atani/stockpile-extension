Auto Extract ZIP Files

Automatically extract downloaded ZIP files and remove unnecessary __MACOSX folders. Download the script for your OS and follow the setup instructions.

Setup Instructions

macOS

  1. Download the script and save it to a convenient location
  2. Open Terminal and run: chmod +x /path/to/auto-extract-mac.sh
  3. Edit the script to set your Stockpile folder path
  4. Run the script manually or set up a LaunchAgent for automation

Windows

  1. Download the script and save it to a convenient location
  2. Edit the script to set your Stockpile folder path
  3. Right-click the .ps1 file and select "Run with PowerShell"
  4. For automation, set up a Scheduled Task in Windows Task Scheduler
