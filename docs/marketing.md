# Marketing Plan

## Positioning Summary
「素材のダウンロードが散らかる問題」を自動で解決し、制作フローを整える拡張機能。

## Launch Channels
- Chrome Web Store の既存リスティング最適化
- GitHub README と Issue/Discussions
- クリエイター向けコミュニティ（Reddit、Discord、掲示板）
- ストック素材サイトのユーザーコミュニティ/フォーラム
- X/Twitter（制作Tips系の投稿）

## Store Listing Notes
- 主要ユースケースを1画面で理解できるスクショ/動画
- 「どのサイトに対応」「どのフォルダに整理されるか」を明記
- 検索/再利用の時短を具体的に伝える（例: 探す時間の短縮）

## 4-Week Launch Plan
1週目: リスティング改善、スクショ/説明文整理、FAQ整備  
2週目: コミュニティ投稿（制作ワークフロー改善の文脈で紹介）  
3週目: 使い方Tipsの短い記事/スレ投稿（3本程度）  
4週目: 反応の良い訴求に寄せた改善 + 次機能アンケート

## Content Plan
- 「素材整理の時短ワークフロー」紹介
- 対応サイト別の使い方ミニガイド
- よくある整理ルール（命名・カテゴリ分け）

## Metrics and Tracking
- CWSインプレッション→インストール率
- 7日後アクティブ率
- 機能利用率（自動整理/検索/エクスポート）
- 有料機能のクリック率（将来の導線確認）
